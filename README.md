# 🎵 CodeAlpha - Music Player

An interactive, responsive web-based music player developed as part of the **CodeAlpha Frontend Development Internship** (Task 2).

## 🚀 Features
- **Playback Controls:** Play, pause, forward, rewind, and track progression.
- **Track Scrubbing:** Interactive seek bar with dynamic current time and duration display.
- **Metadata Display:** Shows track title, artist name, and album cover art.
- **Responsive UI:** Clean, modern layout built for mobile, tablet, and desktop viewports.

## 🛠️ Tech Stack
- **HTML5:** Semantic markup structure
- **CSS3:** Responsive layout, flexbox, custom styling
- **JavaScript (ES6):** HTML5 Audio API, DOM manipulation, event handling
